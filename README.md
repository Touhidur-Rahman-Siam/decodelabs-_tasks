# DecodeLabs AI Engineering — Industrial Training Kit (Batch 2026)

Submissions for Projects 1–3, completed as part of the DecodeLabs AI
Engineering track.

## Projects

### [Project 1: Rule-Based AI Chatbot](./Project1_RuleBasedChatbot)
A dictionary/hash-map based chatbot (O(1) lookup) with sanitized
input handling and a clean exit strategy.
**Skills:** Control flow, dictionary lookups, IPO model.

### [Project 2: Data Classification Using AI](./Project2_DataClassification)
A K-Nearest Neighbors classifier trained on the Iris dataset, with
feature scaling, train/test split, and full validation (confusion
matrix, accuracy, F1 score).
**Skills:** Supervised learning, scikit-learn, model evaluation.

### [Project 3: AI Recommendation Logic — Tech Stack Recommender](./Project3_TechStackRecommender)
A content-based recommendation engine that maps user skills to job
roles using TF-IDF vectorization and Cosine Similarity.
**Skills:** Feature extraction, similarity scoring, recommendation
systems.

## How to run any project
Each project folder has its own README with exact setup and run
instructions. In general:
```
pip install -r requirements.txt   # or see each project's README
python3 <script_name>.py
```
